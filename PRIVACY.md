# What DPI stores

DPI reads a network you are allowed to monitor. It does not decrypt pages, videos, or searches.

It stores a report on this computer only. The report can include addresses, ports, packet counts, sizes, timing, a site name if the handshake showed it, and an app guess from that name. It does not send the report anywhere.

Delete `dpi-output` or `live-output` to remove a report. Do not share a report if you do not want those addresses seen.

# Commit this version

1. Unzip this folder over the existing DPI folder.
2. Delete the old report.py if it is still in the DPI folder root. The report writer is dpi/report.py.
3. In Visual Studio Code, open the DPI folder.
4. Open Source Control.
5. Commit message: Add app names, device count, window, and notes
6. Click Commit, then Sync or Push.

The notes for readers are in NOTES.md and at the top of each Python file.
